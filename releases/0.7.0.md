# 0.7.0

Adds provider-neutral, explicitly reviewed adoption of a compatible managed connection by a new
installation revision. The service independently checks the exact approved packages, deployment,
original actor, profile revision, unchanged consent definitions and all operations available under
the granted scope sets. It retains original consent and encrypted vault bytes, changes only the
current package/installation binding, and writes an immutable adoption receipt atomically.

New Protocol clients support compatibility preview, idempotent adoption, receipt recovery and
cancellation tombstones. Adoption does not create consent, export credentials, invoke a provider,
grant execution policy, restore agent permissions or certify any deletion/backup erasure.

The additive Adoptions table and immutable-receipt triggers require an explicit service schema
upgrade to 0.7.0. Existing 0.6 clients retain their existing contracts. Core's compatible-upgrade
flow must be deployed separately and must enforce human review and native grant/ownership rules.

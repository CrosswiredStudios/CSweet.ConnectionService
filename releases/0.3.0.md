# 0.3.0 — modular managed account connections

Unpublished development release. No service deployment or real-provider acceptance is implied.

- Separate the executable, provider-neutral module core, OAuth implementation, Google credential-import
  adapter, and BCL-only protocol package. No mobile-link implementation is included.
- Keep Google scope aliases and OpenID authorization-scope ordering in its adapter. Additional
  provider incremental-consent scopes never become unrequested service permissions.
- Implement reviewed bootstrap inventory, encrypted pagination checkpoints, serialized refresh,
  provider-confirmed revocation and primary credential erasure.
- Add native C-Sweet deployment pairing/proof validation, human/browser-bound consent return,
  sanitized account/resource import and explicit customer-owned profile selection.
- Recover abandoned attempts by local identity; cancellation tombstones fence late initiation.
  Verified same-identity reconnects retire old service authority without revoking replacement consent.
- Share bounded request-schema validation and verify a fresh NuGet-only consumer.
- Add explicit SQLite upgrades, trusted-proxy configuration, a Dockerfile, secure Google export import
  and Mac Studio/Cloudflare hosting instructions. Shared credentials are never shipped to customers.

General managed operations/approvals, media transfer, complete distributed cleanup, quotas, interactive
control-plane enrollment, cloud KMS and real-provider production acceptance remain unfinished.
